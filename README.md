## 📌 Overview

A modern full-stack web application designed for educational institutions to manage student admissions, attendance, online gradebooks, courses, and teacher-parent communication.

---

## ✨ Key Features

- 👨‍🎓 **Student & Teacher Portals**: Role-based access control with personalized dashboards.
- 📝 **Online Examination & Grading**: Create tests, submit assignments, and generate report cards.
- 📅 **Attendance & Timetable Tracker**: Automated daily attendance tracking and schedule management.
- 💬 **Notice Board & Announcements**: Real-time notifications for school events and updates.

---

## 🛠️ Tech Stack & Tools

- **JavaScript / TypeScript**
- **React.js**
- **Node.js / Express**
- **MongoDB**
